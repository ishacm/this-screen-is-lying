# THIS SCREEN IS LYING

An interactive browser art experiment about how easily our eyes can be fooled.

I made this because I wanted a website you could **feel** through your mouse, not just scroll through. It has 18 strange visual worlds that share one memory: what you do in one world influences the others.

## Try it

Open `index.html` in a browser. Move, click, drag, switch worlds with the arrow keys, and alter reality.

## Why

A tiny exploration of perception, digital materials, and what happens when a screen stops behaving like a screen.
